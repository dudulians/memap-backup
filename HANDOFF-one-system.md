## Её правила, которые нельзя нарушать
- Решения показывать картинками «было / стало» на настоящих экранах, не списками. Экраны по-английски, чат по-русски.
- Короткие подписи, без мелкого текста; ничего не листается вбок; без цветных выделений и подчёркиваний.
- Страница вещи живёт только на острове. «More for today» не должен быть постоянной плашкой.
- Её слова выигрывают: свой или переименованный вопрос не переписывать.
- Про проверки не рассказывать подробно: только «всё цело» или «сломалось вот это».
- Спрашивать перед публикацией в сторы, отправкой и тратами. Отправка ветки и меток на GitHub и обновление ссылки для телефона разрешены после каждого круга.

## Как запускать
- Сервер разработки: preview `memap-dev` (порт 8080).
