# MeMap: концепция «дверей» (решение 26.10.2026)

Контекст: Mixpanel за 3 месяца показал, что 77% прошедших онбординг ни разу не
заканчивают дневную сессию, 70% не открывают приложение второй раз, до первой связи
доходят 2%. Утечка в первый день. Решение: вход через одну конкретную боль, запись
события в момент, мгновенный ответ после каждой записи. Движок (вопросы, календарь,
связи, уведомления) не меняется. В сторе главная страница остаётся нейтральной,
под каждую боль делается Custom Product Page.

Двери на старте: ссоры в паре (главная, продвигаем), мигрень, алкоголь, срывы на
ребёнка, «своё» (старый интервью-онбординг).

## Первая неделя пользователя, дверь «ссоры»

**День 0, установка.** Экран «С чем ты пришёл?» с пятью дверями, одна кнопка.
Дверь «ссоры» сразу спрашивает: «Когда была последняя ссора?» (сегодня / вчера /
на неделе / давно) и «Из-за чего?» (чипы: деньги, быт, дети, усталость, ревность,
не помню). Это уже первая запись: приложение не пустое. Потом три контекстных
вопроса одним экраном: «В ту ночь спала нормально?», «Накануне был алкоголь?»,
«День был тяжёлый?». Экран ответа: «Записано. Первая ссора в журнале. Люди
вспоминают 2–3 ссоры в месяц, а насчитывают 8–10. Через две недели я покажу, что
обычно идёт перед ними». Под ним превью на демо-данных: календарь месяца с
точками ссор и одна строка-связь. Напоминание включается само (как в 1.7.9), но
текст другой: «Вечером спрошу одной строкой, была ли ссора. 10 секунд».

**Главный экран после двери.** Сверху большая кнопка «Ссора» (записать сейчас,
с теми же чипами «из-за чего») и счётчик: «1 за 7 дней». Ниже строка-эхо (см.
ниже). Вечерняя сессия остаётся, но для двери это максимум 3–4 карточки: ссора,
сон, алкоголь, тяжёлый день. Не 8–10 карточек из стартового пака.

**День 1.** Вечером пуш «Была ли сегодня ссора?». Открыл, три свайпа, закрыл.
Эхо: «День без ссор. Всего 1 за 2 дня».

**Дни 2–6.** Эхо после каждого вечера говорит только факты и счёт, без выводов:
«Вторая за 4 дня», «Обе ссоры после плохого сна. Рано для вывода, продолжаем»,
«5 вечеров подряд отвечено». Записи с кнопки «Ссора» днём тоже попадают в эхо.

**День 7.** Карточка недели: «7 дней: 3 ссоры. Чаще по будням, вечером. Перед 2
из 3: плохой сон. Память бы сказала «одна-две»». Это первый момент, которым можно
поделиться (позже: recap).

**День 14.** Первая настоящая связь из движка (7 общих дней, 4 совпадения).
Экран «ого». Здесь позже будет paywall.

## Что меняется в коде

1. `src/lib/doors.ts` (новый). Описание дверей: id, название, главный шаблон
   (для ссор: `argued-with-partner`), контекстные шаблоны из библиотеки (сон,
   алкоголь, тяжёлый день), чипы причин, тексты уведомлений, шаблоны эхо.
2. `src/components/OnboardingTour.tsx`. Вместо пяти шагов (aboutYou, focus,
   context, goal, stackReveal) один экран выбора двери и один экран первой записи.
   Дверь «своё» ведёт в старый интервью-онбординг без изменений.
3. `src/lib/starterGenerator.ts`. Новый путь `generateDoorPack(doorId)`: создаёт
   главный вопрос и 2–3 контекстных, период/порог берёт из шаблона.
4. `src/types/tracker.ts`. В `TrackerEntry` добавить необязательное поле
   `tags?: string[]` (чипы причин). Модель «один ответ да/нет в день» не трогаем,
   движок связей работает как есть.
5. `src/components/DoorHero.tsx` (новый) в верхней части `TodayTab`: кнопка
   записи, счётчик, строка эхо. Показывается только если выбрана дверь.
6. `src/lib/echo.ts` (новый). Чистые подсчёты по записям: N за M дней, K из N
   с контекстом X, серия вечеров. Никакой статистики, только счёт и факты, с
   пометкой «рано для вывода», пока движок связей молчит.
7. `src/components/DailySession.tsx` / `TodayTab.tsx`. Для двери колода
   ограничена картами двери (3–4). Остальные вопросы пользователь добавляет сам.
8. `src/lib/notifications.ts`. Тексты пушей из `doors.ts` (механизм «вопрос в
   теле уведомления» из 1.7.9 уже есть).
9. `src/components/WeeklySummary.tsx`. Карточка недели для двери: счёт, когда
   чаще, контекст перед.
10. `src/lib/analytics.ts` + вызовы. Новые события: `door_selected {door}`,
    `first_entry_logged`, `hero_logged`, `checkin_completed {cards}`,
    `echo_shown {kind}`, `app_foregrounded` (слушатель `App.addListener('resume')`
    из `@capacitor/app`, чтобы возвраты из фона считались).
11. Существующие пользователи ничего не теряют: дверь предлагается только новым
    установкам; старым один раз показываем мягкое предложение «выбрать фокус».

Не в коде: Custom Product Page «ссоры» в App Store Connect (6 скриншотов, свой
текст), ссылка на неё в рекламе, Reddit и Instagram. Главная страница без слова
«ссоры».

## Порядок работ

Сессия 1: doors.ts, онбординг с дверью, generateDoorPack, DoorHero, echo.ts.
Сессия 2: аналитика (новые события, app_foregrounded), тексты пушей, ограничение
колоды, предложение старым пользователям.
Сессия 3: карточка недели, скриншоты для Custom Product Page, TestFlight.
Подписка и paywall на «ого»-экране: после того как до дня 14 начнёт доходить
хотя бы 15–20 человек из 100.
