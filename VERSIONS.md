# Версии MeMap: что где лежит

Весь код хранится на GitHub: https://github.com/dudulians/memap-backup.
Ветка — это версия, которая ещё меняется. Метка (tag) — это снимок, который не меняется никогда.

| Версия | Где лежит код | Ссылка для телефона |
|---|---|---|
| **Сейчас в App Store (1.7.9)** | ветка `main` и метка `v1.7.9-live` (к ней можно откатиться) | — |
| 1.8.0 (не собиралась) | ветка `release/1.8.0` | — |
| **Розовая версия со стикерами** (архив от 31 окт. 2026) | метка `archive/sticker-diary-2026-10-31`, ветка `design/malu-world` | https://claude.ai/artifact/NFmgCod55uLGoCq77j4stD — не перезаписываем |
| **Новая версия Aurora** (в работе) | ветка `design/aurora-ux`; снимки — метки `aurora/v16` … `aurora/v20`… (номер = версия ссылки для телефона) | https://claude.ai/artifact/5RQUsU2CcaRKKHyoowZpaF — каждая версия остаётся в истории ссылки |

Внутри новой версии есть «классический режим» (папка `src/classic/`): те, кто начал пользоваться до 1.8.0, видят прежние экраны 1.7.9 со всеми своими ответами.

## Как открыть любую версию

- Посмотреть на сайте: на GitHub выбрать ветку или метку в списке веток (кнопка с названием ветки над файлами).
- На компьютере: `git checkout <ветка или метка>`.

## Когда новая версия выйдет

`main` переедет на неё, а метка `v1.7.9-live` останется точкой отката.
